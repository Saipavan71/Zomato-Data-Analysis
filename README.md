# Zomato Data Analysis using Python

## Project Overview
This project analyzes Zomato restaurant data using Python, Pandas, and Matplotlib to uncover insights related to cuisines, ratings, pricing, and restaurant trends.

## Analysis Performed
- Top Cuisines Analysis
- Restaurant Ratings Analysis
- Cost Distribution Analysis
- Online Delivery Insights
- Restaurant Type Distribution
- City-wise Restaurant Trends

## Technologies Used
- Python
- Pandas
- Matplotlib

## Files Included
- zomato_analysis.py
- zomato.csv
- cleaned_zomato.csv

## Key Skills Demonstrated
- Data Cleaning
- Null Value Handling
- Exploratory Data Analysis (EDA)
- Data Visualization
- Aggregation & Filtering

## Visualizations
- Bar Charts
- Pie Charts
- Rating Distribution Charts

## Dataset
Zomato restaurant dataset used for exploratory analysis and visualization.
