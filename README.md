# Netflix SQL + Python Analysis

## Project Overview
This project analyzes Netflix movies and TV shows data using SQL, Python, Pandas, and Matplotlib.

## Technologies Used
- Python
- Pandas
- Matplotlib
- MySQL

## Key Analysis Performed
- Movies vs TV Shows
- Top Countries
- Release Year Trends
- Ratings Analysis
- Genre Analysis
- Longest Movies
- Top Directors
- Top Actors

## Skills Demonstrated
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- SQL Queries
- Aggregation & Filtering

## Dataset
Netflix Movies and TV Shows Dataset from Kaggle.
